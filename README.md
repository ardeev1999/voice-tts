# TTS from Files – Озвучка текста через Yandex SpeechKit

Утилита для синтеза речи из текстовых файлов с использованием API Yandex Cloud SpeechKit. Позволяет создавать аудиофайлы (MP3) с голосовым чтением любых текстов. Оптимизирована для поэтических и ритмичных текстов (паузы, интонации), но работает с любым текстом.

## Возможности

- Чтение текста из файлов (кодировка UTF-8, CP1251)
- Пакетная обработка всех `.txt` файлов из папки `texts/`
- Настройки голоса: скорость, эмоция, формат
- Поэтический режим: автоматическая расстановка пауз, обработка ударений
- Создание отчёта о синтезированных файлах

## Требования

- Python 3.8+
- Аккаунт в [Yandex Cloud](https://cloud.yandex.ru/) с активированным SpeechKit
- API-ключ и идентификатор каталога (Folder ID)
